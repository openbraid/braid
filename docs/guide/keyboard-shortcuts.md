# Keyboard Shortcuts

Braid uses three levels of keyboard shortcuts depending on what's focused.

## Global shortcuts

These work everywhere in the app, regardless of what's focused.

| Shortcut | Action |
|---|---|
| **Ctrl+Shift+.** | Switch to next workspace tab |
| **Ctrl+Shift+,** | Switch to previous workspace tab |
| **Ctrl+Shift+W** | Close current workspace tab |
| **Ctrl+Shift+S** | Toggle scratch panel |

## App shortcuts

These work when the VS Code editor is **not** focused — i.e., when you're in the Braid chrome (sidebar, project page, artifact tabs).

| Shortcut | Action |
|---|---|
| **Ctrl+Shift+N** | Create new workspace |
| **Ctrl+Shift+O** | Open workspace list |

## Terminal shortcuts

These work when a terminal is focused inside VS Code.

| Shortcut | Action |
|---|---|
| **⌘T** | New terminal |
| **⌘D** | Start dictation |
| **F2** | Rename current terminal |

## Viewing shortcuts

Open the keyboard shortcuts reference anytime from the Help menu.
